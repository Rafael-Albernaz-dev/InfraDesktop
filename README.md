# InfraDesktop

Local desktop operations workspace for ISP technicians, independent from Atlas. The planned stack is Go/Wails, a local Go service and SQLite. Ubuntu 24.04 is the initial Linux target; inference is optional.

## Current status

Preparation stage only: no application, installer or service is available to run yet. Product CI and executable instructions will be introduced with the first foundation slice. No performance benchmark or operational device support is claimed.

Agent instructions, skills and preparation documents are private local workspace material and are not included in this repository. Official product documentation will be provided separately.

No product license has been selected.
